# Fichas de marcas (clientes de la agencia)

Datos que ya se relevaron. Las condiciones comerciales cambian: **volvé a mirar la web** antes de
usarlas (fecha de relevamiento entre paréntesis). Para una marca nueva, armá una ficha igual.

## Ficha de marca nueva (qué relevar de la web)
- Rubro y público; tono (cercano, lujo, urbano…).
- Colores: fondo, texto, botones, barra de anuncios, color del precio con transferencia.
- Tipografías: títulos, texto, botones (inspeccionar o comparar con Google Fonts).
- Logo (PNG transparente; si es blanco, placa de color detrás).
- Condiciones: % transferencia, cuotas, envío gratis desde, local.
- Productos del guion: nombre exacto, URL, precio de lista y con transferencia, variantes.
- Rarezas: datos contradictorios en la web, productos sin página, nombres parecidos.
